# 环卫刷盘磨耗核验业务规格

## 输入与时点

`day` 从演练档案起始日计数，`arrived` 表示入账日，`clock` 以 15 分钟为一格。测量在发生日之后一日内到达才可进入时点样本，超过窗口的补录留在隔离证据。跨日结果通过 `available` 回读，训练使用冻结日前已确认的最后一份回执。

业务组包括广场软刷、高架辅路、旧街石砖、环线重扫。同一 `case_id` 的同版本异值记录整笔隔离，重复记录只计一笔。

| 信号源 | 含义 | 接受范围 |
| --- | --- | --- |
| `hours` | 累计作业 h | 2 至 270 |
| `abrasive` | 粗粒路段 % | 0 至 95 |
| `rpm` | 刷盘转速 rpm | 50 至 235 |
| `downforce` | 刷盘压力 N | 30 至 220 |
| `grit` | 粗砂负载 kg | 0 至 29 |
| `service_at` | 距离出勤 min | 0 至 145 |
| `compatible` | 是否有互换备件 | 0 至 1 |

## 计算与裁决

使用池相邻违例单调回归，目标单位为 mm。数据冻结以 `as_of` 为锚点，选择截至第 `as_of-64` 日的历史，随后依次保留校准段、回放段和待裁决段。
训练样本的中位数与 MAD 用于共享缩放。组内样本数足够时，用组内中位数补齐非关键测量。以下特征按同一名次供回放和推理。

| 派生特征 | 计算 |
| --- | --- |
| `equivalent_duty` | `hours * (0.40 + abrasive / 110) * (0.60 + rpm / 220) / 300` |
| `contact_load` | `downforce / 220` |
| `grit_load` | `grit / 29` |
| `concrete_share` | `abrasive / 95` |

关键测量不全、回放门限失败或组分布出现明显变化时进入人工复核。业务锁包括无适配备件或即刻需要出勤。最终分派受出勤前核验槽总额和组内上限约束，使用额度守恒回读工作单。

## 换盘门槛与漏报复核

换盘门槛为 9.5 mm。回放里的回执可能是提前换盘后留下的磨耗下限（删失），不是完整实测值：

- 下限本身已过门槛的刷盘按越界处理，不能当下限「未实测」而漏算。
- 预测未过门槛、实际已过门槛的刷盘计为漏报。
- 按业务组核对越界刷盘的漏报率。没有确定越界证据的组、以及最不利实测值会让漏报率超过两成的组，整组转人工；转人工的单据不占用换前核验工位，其余达标组照常锁位。

门槛比较一律使用未舍入的读数，浮点舍入误差不得改变是否达标；两成按整数比例核对，避免舍入把 20% 抬过线。

## 时点与回执边界

晚到的补测记录不进入当班回放：超过发生日一日到达的测量留在隔离证据。截止前已经有效的旧回执仍然作数，后续补测不会改写当班结论。提前换盘留下的下限不进入训练，只在回放核对时按越界证据处理。
